# Tools & Routing

Tools die AI in jeder Session kennen soll. Lebende Datei.

## Verbundene Tools (MCPs)
> ⚠️ Im Onboarding eintragen — nur Tools listen, die wirklich verbunden sind. Nicht-Genutztes löschen.
- **Google Calendar** (`{{USER_CAL_EMAIL}}`) — Termine, Timeboxing.
- **Linear** — Engineering-/PM-Issues. Quelle für Team-Arbeit (mehrere Beteiligte).
- **Notion** — Workspace für ausformulierte Doku-Outputs. **NICHT SSOT** — Vault ist authoritative source.
- **Slack** — interne Kommunikation. Quelle für Capture-Eingehende.
- **Gmail** — E-Mail-Zugriff. Markierte Mails on-demand.

## Vault als Persönliche Fläche
Founder OS Vault (dieses Repo, Obsidian) = persönliche Arbeitsfläche. Tasks, Notizen, Capture, Decisions, Entities.

Linear = kollaborative Team-Arbeit. Vault = solo.

## Routing-Regel: Linear vs. Vault
**Kriterium:** Führt jemand anderes außer User aus?
- **Ja → Linear** (Team nimmt Teile auf)
- **Nein → Vault** (Tasks in Daily/Domain/Project-Page)

Egal wie team-relevant das Ziel ist.

## Übergabe Linear → Vault
Linear-Issue bleibt Quelle. Nie ganze Projekte spiegeln.

Nur **nächster fälliger Schritt** wird Vault-Task (Daily-Note oder Project-Page).
